# NeetCode Roadmap Solutions 🚀

This repository contains my solutions to problems from the **[NeetCode Roadmap](https://neetcode.io/roadmap)**.  
It is organized by **patterns** and **data structures**, making it easier to navigate and revisit problems.

---

## 📂 Folder Structure

- **Arrays_and_hashing/** → Problems involving arrays, hash maps, and hash sets.
- **Backtracking/** → Classic recursion and backtracking problems.
- **Recursion/** → Problems solved using recursion techniques.
- **Sliding_window/** → Problems solved with the sliding window pattern.
- **Stack/** → Stack-based problems
- **Two_pointers/** → Two-pointer and fast-slow pointer techniques.
- **binarysearch/** → Binary search and its variants.
- **dp/** → Dynamic Programming problems (1D, 2D, etc.).
- **graphs/** → Graph traversal, BFS, DFS,and more.
- **heap/** → Priority queue and heap-based problems.
- **linked_lists/** → Singly and doubly linked list problems.
- **trees/** → Binary trees, BST, and tree traversal problems.
